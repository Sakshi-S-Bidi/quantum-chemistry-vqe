# Quantum Chemistry using VQE on Fujitsu Quantum Simulator

## Overview
This project explores Variational Quantum Eigensolver (VQE) techniques for quantum chemistry simulations using the Fujitsu Quantum Computing Simulator.

## Features
- LiH molecule simulation
- Multi-start VQE optimization
- Ansatz depth comparison
- Binding energy variation analysis
- MPI-based execution on HPC systems

## Technologies Used
- Python
- Qulacs
- MPI
- Fujitsu Quantum Simulator
- Quantum Chemistry

## Files
- vqe_lih.py
- binding_variation.py
- ansatz_depth.py

## Objectives
- Study molecular energy optimization
- Analyze variational circuit behavior
- Explore quantum computing applications in drug discovery

## Future Work
- Real molecular Hamiltonians
